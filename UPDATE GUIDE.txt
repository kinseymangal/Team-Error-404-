NayanSetu updated project

TO UPDATE YOUR EXISTING PROJECT (preserves patients and images):
1. Stop the running app with Ctrl+C.
2. Back up your existing project folder.
3. Copy the contents of this NayanSetu-MERN folder into D:\Hackathon\NayanSetu-MERN, replacing matching source files.
4. Keep your existing .runtime, uploads, .env and node_modules folders. This ZIP does not contain or overwrite patient data.
5. Run npm.cmd run dev in the project folder.
6. Open http://127.0.0.1:5173 and press Ctrl+F5.

FRESH INSTALL:
Extract the ZIP, open its NayanSetu-MERN folder in VS Code, run npm.cmd ci, then npm.cmd run dev.
AI model files are included. First startup may download MongoDB if it is not already installed in the project runtime.

NEW FEATURES:
- Indore hospital directory: Sankara Eye Centre, Eye Site Eye Hospital & Retina Centre, Centre for Sight Vijay Nagar.
- English/Hindi interface switch.
- Image Reports: per-eye explanations, segmentation tab, numbered model candidate regions, reviewer-drawn circles, heatmaps with opacity and legend, printable bilateral reports.
- Fixed heatmap pixel indexing: resized grayscale output was previously expanded into 3 channels but indexed as 1 channel. It now explicitly stays single-channel.
- Unreliable broad/overlapping lesion masks are suppressed instead of drawing misleading defect circles.
- Reviewed patients can save appointment requests, open official hospital booking/contact pages, and record hospital confirmation.
- Camp-to-Care: follow-up, attendance, escort/transport needs, automatic grouping by area/hospital/date, capacity, coordinator, pickup and vehicle details.

DEMO WALKTHROUGH:
Load sample workflow, analyze images, open Image Reports, select an eye and inspect its guidance. For reviewer marks, enter a label and reviewer name, then drag diagonally across an image and save. Complete doctor review. In Camp-to-Care choose hospital/date, contact the hospital separately, and record confirmed appointment details. Enable transport help to create a group in the Transport grouping tab.

LIMITATIONS:
No hospital booking API is configured: saving a request does not send it to a hospital or reserve a slot. Official links and calls require internet. Record confirmation only after the hospital confirms.
The existing lesion model is not clinically validated and has low development Dice scores (approximately 0.015-0.127). This update does not retrain it or guarantee accurate lesions. Some images correctly show no automatic circles because the masks are unreliable; a reviewer can annotate them.
Grad-CAM is coarse model attention, not a defect segmentation or diagnosis. Old stored heatmaps must be regenerated by re-uploading the photograph. Re-analysis clears the old review.
Reviewer names are audit fields, not authenticated clinician identities. Use sample data for hackathon demonstrations.
Original photos remain in uploads, patient records in MongoDB, and transport plans in the trips collection. JSON export includes trips and records but excludes original image files. Remote record sync does not sync trip records or original photographs.

VALIDATION:
20 automated tests passed, including real ONNX inference, MongoDB/API workflow, annotations, appointment confirmation, grouping and registration. Production build passed. Browser visual testing was not completed because the preview could not reach the isolated test server.
